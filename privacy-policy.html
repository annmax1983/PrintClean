PrintClean Privacy Policy

PrintClean does NOT collect, store or transmit the pages you read, the text it extracts, or any personal information. Extraction and typesetting happen inside your browser tab; the cleaned article waits in the extension's memory and is deleted as soon as the sheet reads it. The only network request the extension makes is the optional Pro licence check in Section 4.

01Data Collection

PrintClean collects nothing. There is no account, no analytics, no telemetry, no crash reporting, no advertising identifier and no tracking pixel.

Specifically, the extension does not send anywhere:

  • the address of any page you clean or print;
  • the text, images or markup it extracts;
  • the selectors or site rules you type;
  • the contents of a batch list.

The pages you clean are read in the tab where they already are, from the copy your browser has loaded. PrintClean never fetches a page on your behalf in single-page mode.

02How PrintClean Reads a Page

When you press Clean & print, PrintClean runs a script in the current tab through the browser's own scripting API. That script scores the blocks of the page, keeps the article, and builds a cleaned copy: navigation, sidebars, ad slots, cookie banners, share bars, comment threads, newsletter boxes, scripts and inline event handlers are dropped, and image addresses are made absolute.

The cleaned copy is placed in chrome.storage.session — memory owned by the browser, cleared when the browser closes — and a new tab opens to read it. That tab deletes the copy the moment it has rendered, so a second reader cannot pick it up.

Batch mode works differently and is the only feature that uses the network: with your permission it loads each address you listed, extracts the article in the reader tab, and discards the rest of the response. Those requests go directly from your browser to the site you named. No intermediate server is involved, and no copy of the response is kept.

03Permissions Explained

PrintClean asks for the minimum it can work with, and explains each item:

  • storage — remembers your type settings, paper and margin choice, and the selectors you saved per site. Local to this browser.
  • activeTab — grants access to the page in front of you for one action, when you click the toolbar button. It is not a standing permission to read every site.
  • scripting — runs the extraction script in that tab.
  • Host access, requested on demand — batch mode needs to load the addresses you paste, so the first time you start a batch the browser asks whether PrintClean may access pages on the web. Nothing is read before you accept, and the grant can be withdrawn at any time in the browser's extension settings.

PrintClean ships no persistent content script and no background page injection, and it never asks for always-on <all_urls> access: site access is requested on demand, only when you start a batch. It has no access to downloads, the debugger, your tabs' history or your bookmarks, and it never reads your clipboard.

04Third-Party Services & Licence Verification

PrintClean is free. An optional Pro licence unlocks larger batches and custom selectors.

If — and only if — you activate a licence, the extension contacts api.annmax1983.com to check the key. That request contains the licence key, a random installation identifier generated in this browser and basic browser metadata. It is sent when you activate, and afterwards at most once every two hours when you open the popup.

The check is deliberately forgiving: if the server is unreachable, the cached licence keeps working, so a network failure never locks a paid feature. The request is also the only one PrintClean ever makes to a server of ours — no page address, no article text and no selector is included in it.

Payment itself is handled by the payment provider on its own checkout page; PrintClean never sees your card details.

05Data Sharing

Nothing is shared, because nothing is collected. PrintClean has no servers holding user data, no advertising partners, no data brokers and no analytics vendor. There is nothing to sell, and no mechanism to sell it with.

06Data Retention & Deletion

Three kinds of data exist, all of them on your machine:

  • Settings and site rules live in this browser's extension storage until you change them, reset them, or remove the extension. Reset settings in the popup clears them.
  • The cleaned article lives in session memory and is deleted by the reader tab as soon as it renders, or by the browser when it closes.
  • The licence, if you activated one, is cached in this browser so the extension works offline. Removing the licence in the popup deletes it locally and frees the activation slot.

There is no history of the pages you cleaned, and no usage counter that leaves the browser. Removing the extension removes everything it stored.

07Children's Privacy

PrintClean is a general-purpose tool for printing web pages. It is not directed at children, it has no accounts, and it collects no information from anyone, of any age.

08Changes to This Policy

If a future version of PrintClean needs a new permission or a new network request, this page will be updated before that version ships, and the date at the top will change. The current design goal is that this policy stays short: the extension reads a page, typesets it locally, and prints it.
