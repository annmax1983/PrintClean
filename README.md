# PrintClean

Turn the page you are on into a clean printable sheet: the article stays, the navigation, sidebars, ads, cookie banners and comments go. Then print it or save it as a PDF. Everything runs on the device — no account, no analytics, no server.

## What it does

- Extracts the article from the page in front of you and opens it in its own tab, typeset on a paper-like sheet. The original page is never modified.
- Adjustable font size, line height and measure; A4 or Letter; three margin presets; header and footer on or off; black-and-white and images-off switches.
- Print, or use the browser's Save as PDF. Tables, code blocks, quotes and figures are kept off page breaks.
- Batch mode takes a list of addresses and gives each one its own sheet — one article per page, never interleaved.
- Shadow DOM is followed, `<picture>`/`srcset` resolved, lazy images found, 1×1 tracking pixels dropped, every URL made absolute.

**Pro** adds:

- Batch up to 50 pages at a time (free tier: 3).
- Custom CSS selectors — hide anything, or pin what the extractor dropped — remembered per site, with an "everywhere" list on top.
- Rules bundle export and import as a JSON file; importing merges instead of replacing.

## Build

```bash
npm install        # only devDependency: terser
npm run locales    # regenerate the six _locales files from tools/make-locales.js
npm run icons      # bake icons/ + assets/icon-master.png
npm test           # node --test: common logic, extraction, rules bundle, i18n, wiring, manifest
npm run e2e        # real Chrome + fixtures: 49 assertions on extraction and the reader
npm run build      # minify and write publish/printclean-v<version>.zip
npm run verify     # unpack the zip and load the packed popup and reader
node tools/shoot.js  # five 1280×800 store shots + promo.png, from the real popup
```

`npm run icons:preview` writes `assets/icon-preview.png` (three glyph candidates at 220/64/48/32/16) without touching `icons/`.

> This repository is for project presentation; the complete source is not published. Install PrintClean from the official browser stores.

## Store screenshots

`node tools/shoot.js` writes `screenshots/01-…05…png` at 1280×800 (the size the stores require) plus `promo.png` at 1400×560. Each shot is the real popup, with `chrome.*` answered by `tools/harness/mock-popup.js`, rendered inside `tools/harness/stage.html`. The extension itself is not loaded — Chrome 137+ refuses `--load-extension` from the command line. The 440×280 tile is derived from `promo.png` separately.

## Pages

`index.html` and `privacy-policy.html` are the landing and privacy pages shipped with the store listing. Both carry their own six-language `MODEL` and a fixed renderer; edit the MODEL, not the markup. `promo.html` is the 1400×560 promotional tile.

## Design notes

- **No `<all_urls>`, ever.** Single-page printing uses `activeTab` only. Batch mode asks for host access with `chrome.permissions.request` inside the click handler, so the prompt is tied to a user gesture; the grant lives in `optional_host_permissions`.
- **No CDP, no offscreen document, no `downloads`.** The batch runs in the reader tab: `fetch` the listed pages, `DOMParser`, extract, one sheet per article, then the browser's own print dialog. This keeps the build MV3-safe and makes a Firefox twin possible.
- **The article never touches disk.** It is written to `chrome.storage.session` (memory, cleared when the browser closes) and the reader deletes it as soon as it renders.
- **Keep beats hide.** A `keep` selector protects the whole subtree from the junk classifier and both cleanup passes, so a rule written by hand cannot be undone by a heuristic.

## Layout

```
common.js          pure logic: settings, selectors, site rules, URL list, page rule, rules bundle
background.js      messages, scripting.executeScript, payload storage, reader tab
content/extract.js the extractor: scoring, whitelist clone, cleanup, shadow DOM, word count
license.js         Creem licence activation (shared family module)
popup/             the real UI (popup.html / popup.css / popup.js)
reader/            the clean sheet (reader.html / reader.css / reader.js)
_locales/          en, zh_CN, ja, de, es, fr — generated by tools/make-locales.js
icons/             generated by tools/make-icons.js
index.html         landing page, six languages (MODEL + renderer)
privacy-policy.html privacy page, six languages
promo.html         1400×560 store tile
languages/         README_de / es / fr / ja / zh
store-listing/     per-language listing text, CRLF, no browser names
tools/harness/     chrome.* mocks, fixtures and the 1280×800 stage
test/              node --test suites
```

## Repo split

This repository builds the Chrome/Edge package (`background.service_worker`). A Firefox twin, if built, differs only in `manifest.json` (event page instead of a worker), the `chrome.*` → `browser.*` namespace and the packaging script. HTML and README stay in this repo only.
